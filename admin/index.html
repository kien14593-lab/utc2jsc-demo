📖 Hướng dẫn tạo token (1 lần, dùng lâu dài)
  1. Đăng nhập GitHub bằng tài khoản kien14593-lab
  2. Mở github.com/settings/personal-access-tokens/new
  3. Token name: đặt tuỳ ý (VD: utc2jsc-admin) · Expiration: chọn 90 ngày hoặc lâu hơn
  4. Repository access → chọn Only select repositories → chọn utc2jsc-demo
  5. Permissions → Repository permissions → Contents → chọn Read and write
  6. Bấm Generate token → sao chép mã github_pat_… và dán vào ô dưới
Quên mật khẩu / đổi token — thiết lập lại
